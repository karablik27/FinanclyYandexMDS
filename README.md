# Финансовый Укротитель: Поймай свои деньги за хвост! 🐯💰  

## 📖 Описание  
**Финансовый Укротитель** — это приложение для учёта доходов и расходов, анализа трат и управления личными финансами.  

---

## 🚀 Возможности  

- Регистрация **доходов** и **расходов**  
- Экран **анализа операций** (фильтрация + сортировка)  
- **Гистограммы** динамики трат  
- **Круговые диаграммы** по категориям  
- Экран **“Мой счёт”** с балансом и выбором валюты  
- Экран **“Моя история”** с выбором периода и подсчётом суммы  
- Экран **“Мои статьи”** с поиском и fuzzy search  
- Экран **аналитики (UIKit)** с таблицей и графиком (PieChart)  
- Локальное хранилище (SwiftData / CoreData) + бэкап несинхронизированных операций  
- Сетевой слой с авторизацией (Bearer Token)  
- Поддержка **оффлайн-режима**  
- Анимация запуска через **Lottie**  

---

## 🛠 Технологии  

- **SwiftUI** — основной UI приложения  
- **UIKit** — экран анализа  
- **SwiftData / CoreData** — локальное хранение  
- **SPM** — зависимости (`Charts`, `Lottie`, кастомный модуль `PieChart`)  
- **Concurrency (async/await)** — асинхронные сервисы  
- **NetworkClient** — работа с API  
- **Charts** — графики по балансу  
- **Lottie** — анимация запуска  

---

## 📊 Структура приложения  

- **Tab Bar**:
